# Launch checklist

- [ ] Corporate/business account approved by each payment provider
- [ ] Legal and regulatory review completed
- [ ] KYC/AML and consumer-protection program approved
- [ ] Production provider contracts and credentials received
- [ ] Real SMS OTP provider configured
- [ ] Funding-source flow implemented and approved
- [ ] Provider adapters implemented from official specs
- [ ] Idempotency tests pass under retries/timeouts
- [ ] Webhook replay/signature tests pass
- [ ] Daily reconciliation and exception queue implemented
- [ ] User limits and fraud rules enabled
- [ ] Privacy policy, terms, fees, refund/dispute flow published
- [ ] Security review and penetration test completed
- [ ] Monitoring, alerts, incident response, backups tested
- [ ] Small-value controlled production pilot completed
